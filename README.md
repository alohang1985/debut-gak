# 데뷔각

내가 아이돌이 되는 연예계 인생 시뮬레이션. 나중엔 내 기획사와 방송국을 키웁니다.

- **1막 · 내가 아이돌이 되는 길**: 오디션 → 월말 평가 → 데뷔조 → 포지션 선택 → 데뷔 → 컴백 콘셉트를 직접 골라 차트 도전 → 7년 차 재계약 갈림길
- **2막 · 내 기획사**: 오디션과 길거리 캐스팅, 숨은 사연이 있는 연습생, 트레이닝, 그룹 결성과 데뷔, 컴백, 투어, 사옥과 해외 진출. 1인 기획사에서 글로벌 엔터까지
- **2막 · 내 방송국**: 장르 · 제작비 · 섭외를 골라 프로그램 기획, 첫 방송 시청률, 시즌 2, 채널 등급. 개인 채널에서 지상파급 방송국과 글로벌 OTT까지
- 회사는 내 직업과 따로 굴러갑니다. 오디션에 붙어도 회사는 그대로입니다
- 손으로 쓴 사건 150여 개, 13만 가지 조합 사건. 분기마다 팝업은 많아야 두어 개
- 시장(회사 · 건물 · 주식 · 수집품), 은행 대출과 사채
- 진행 상황과 도감은 각자의 브라우저에 저장됩니다. 홈 화면에 앱으로 설치할 수 있습니다

`index.html` 하나로 동작합니다. 모든 회사 · 방송사 · 인물 · 노래 제목은 가상입니다. 투자 요소는 게임 속 가상 자산입니다.
